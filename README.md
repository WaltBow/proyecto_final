# Proyecto Final – MLOps

Este proyecto es parte del curso de MLOps de Universidad LEAD. Consiste en el desarrollo de una aplicación de Machine Learning que entrena un modelo de clasificación, lo sirve mediante una interfaz gráfica con Streamlit, y está lista para producción usando contenedores Docker, automatización con GitHub Actions y despliegue en la nube con Amazon EC2.


Funcion

- Entrena un modelo `RandomForestClassifier` para clasificar flores Iris
- Carga el modelo desde un archivo `.joblib`
- Interfaz gráfica hecha con Streamlit
- Contenerizado con Docker
- Automatización de reentrenamiento con GitHub Actions
- Se ejecuta en una instancia EC2 (AWS)
